# Screenshot provenance

`seroslop-results.png` is output from the project-owned Chrome E2E fixture.

- Real fixture: [“Méduses, Oceanopolis, Brest”](https://www.flickr.com/photos/alainlm/3548073223/) by [alainlm](https://www.flickr.com/people/alainlm/), licensed [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/).
- Synthetic fixture: HunyuanImage-3.0 item from [Qwen/Qwen-Image-Bench](https://huggingface.co/datasets/Qwen/Qwen-Image-Bench), whose pinned dataset revision is declared Apache-2.0 in `tests/fixtures/model-states/fixture-manifest.json`.

`seroslop-modes.png` and `seroslop-mobile-install.png` show only SeroSlop interface surfaces. Store listing assets are generated from the mode-selection screenshot and the SeroSlop logo; they do not reproduce the image fixtures above.
