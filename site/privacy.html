Privacy

SeroSlop analyzes images locally.

SeroSlop does not upload webpage images, scores, browsing history, or model inputs to a detector service. The packaged model runs in Chrome through WebGPU or WebAssembly.

What stays on the device

The extension stores the verified model, setup state, selected mode, and bounded operational state in Chrome extension storage. It does not include telemetry or advertising.

Page access

Page access lets SeroSlop discover supported images and attach scores to the images it analyzes. Extension code does not fetch page-controlled image URLs.

Contact and source

Review the complete privacy contract, source code, and security documentation in the public repository.
