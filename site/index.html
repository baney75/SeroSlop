A local image check
for the pages you browse.

SeroSlop runs one packaged model in your browser and places a score beside supported images. It does not send images to a server or call a detector API.

Source install

Build and load the extension.

Requires Node.js 20.9 or newer and Chrome 121 or newer. Build the extension locally, then load the generated directory as an unpacked extension.

  1. git clone https://github.com/baney75/SeroSlop.gitcd SeroSlop && npm ci && npm run build
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked, then select dist/.
  4. Keep setup open until it says Offline ready, then choose a mode.
